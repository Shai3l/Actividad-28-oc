# Actividad-28-OC


## Descripción libreria: Aniamte.css
Es de código abierto y está escrita en CSS para ofrecer animaciones que ya estàn listas para usar 

## Utilidades

Se pueden añadir de manera rápida y sencilla:

* textos
* botones 
* imagénes 
* contenedores

## Beneficio

No hay necesidad de escribir código de animación complejo desde cero
